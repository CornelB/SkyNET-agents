## Documentation

## Releases
A release is its own commit, `chore: release <x.y.z>`, that bumps `version` in both `.claude-plugin/plugin.json` and `.claude-plugin/marketplace.json`. The SkyNET-marketplace entry for this plugin has no version field and needs no change.
